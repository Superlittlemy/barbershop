# UI 标准规范

## 列表规范

### 列对齐规则

- 金额右对齐
- 数值（计数、百分比）右对齐
- 文本左对齐
- 操作列固定宽度

### 空数据

列表无数据展示文案"暂无数据"或依据业务场景展示例如"暂无交易记录"的文案

### 长文本截断

主列加 `text-overflow: ellipsis; white-space: nowrap; max-width: <合理值>;`，避免撑高行。
如果存在隐藏，支持 hover 查看全部文本。

### 行点击与按钮事件互斥

- 整行可点击：行用 `<a>`（不要用 `<div onclick>`）
- 单元格内按钮：必须在按钮 `onclick` 中 `event.stopPropagation();` 阻止冒泡到行

### 高度

表格本体不允许滚动，且高度自适应；内容撑高时，表格内部滚动；分页栏固定在底部。
